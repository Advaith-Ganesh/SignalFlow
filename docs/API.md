# API Reference

Base URL when running locally: `http://127.0.0.1:8000` (or through the Vite
proxy at `http://127.0.0.1:5173/api/...` — see `frontend/vite.config.ts`).

Every endpoint is `GET` and read-only. There is no authentication, no
request body, and no query parameters anywhere in this API — it serves one
fixed, precomputed research result. Interactive, always-up-to-date docs are
also auto-generated by FastAPI at **`/docs`** (Swagger UI) and **`/redoc`**
once the server is running.

| Method | Path | Returns |
|---|---|---|
| `GET` | `/` | API index: name, links to `/docs` and `/api/health`, and the full endpoint list |
| `GET` | `/api/health` | `{"status": "ok"}` — liveness check |
| `GET` | `/api/event` | Event facts (company, dates, DAU/MAU, guidance, sources) + earnings/revenue surprise |
| `GET` | `/api/market/event-study` | Market-model parameters, daily abnormal/cumulative-abnormal returns, and summary statistics |
| `GET` | `/api/news` | Curated real headlines with VADER sentiment scores, plus daily information intensity |
| `GET` | `/api/diffusion` | Observed absorption-fraction path, fitted exponential/logistic models, comparison metrics |
| `GET` | `/api/results/hypotheses` | All four hypothesis test results (statement, method, statistic, conclusion) |
| `GET` | `/api/results/limitations` | The project's stated limitations, structured for the dashboard's Limitations tab |
| `GET` | `/api/results/summary` | A bundle of headline numbers (surprise, event-day AR, CAR, best diffusion model, absorption times, hypotheses) for a single-call dashboard summary view |

## Example

```bash
curl -s http://127.0.0.1:8000/api/event | python3 -m json.tool
```

## Response shape notes

- All endpoints currently return plain JSON objects (FastAPI-serialized
  Python `dict`s), not Pydantic response models — see the Future
  Improvements section of `README.md` for why, and what a typed version
  would look like.
- Every numeric field is a real value computed by `src/signalflow/`
  (see `docs/ARCHITECTURE.md`) — nothing in an API response is mocked or
  hand-written.
- The result is cached per-process (`backend/app/pipeline_cache.py`); the
  first request after the server starts computes the full pipeline, every
  request after that is served from memory.

## CORS

Only `http://localhost:5173` and `http://127.0.0.1:5173` (the Vite dev
server) are allowed origins, and only `GET` is an allowed method — see
`backend/app/main.py`. A request from any other origin will not receive
`Access-Control-Allow-Origin` headers and will be blocked by the browser.
