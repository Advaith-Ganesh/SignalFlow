# Data

This project distinguishes four kinds of data. Every file in this directory is
tagged with which kind it is so nothing here can be mistaken for something
it's not.

| Kind | Meaning |
|---|---|
| **REAL (raw)** | Directly sourced from a public, citable record. Never edited by hand except for format conversion (e.g. JSON → CSV). |
| **DERIVED** | Arithmetic transformations of real data (returns, abnormal returns, surprises). Fully reproducible from the raw files. |
| **MODEL OUTPUT** | Parameters/curves fit to derived data (the two diffusion models). Reproducible but depends on a chosen model form. |
| **SYNTHETIC** | Not used anywhere in this project. If it ever is, it will be labeled `synthetic_` and documented here. |

## `raw/` (REAL)

- **`meta_prices.csv`, `benchmark_prices.csv`** — Daily OHLCV for META and the
  S&P 500 index (`^GSPC`), June 1 2021 – April 15 2022, fetched from Yahoo
  Finance's public chart endpoint
  (`https://query1.finance.yahoo.com/v8/finance/chart/<symbol>`) — the same
  free, unauthenticated, no-API-key endpoint the popular `yfinance` library
  wraps. Regenerate with `python scripts/fetch_market_data.py`.
- **`earnings_facts.json`** — Hand-transcribed facts about Meta Platforms' Q4
  FY2021 earnings release (EPS, revenue, DAU/MAU, guidance, stock reaction),
  each one cited to a specific publicly accessible article or the original
  earnings call transcript. See the `sources` field inside the file.
- **`news_headlines.csv`** — A small, manually curated set of real headlines
  (title, publisher, date, URL) published before, during, and after the
  event. Only headline metadata is stored — no copyrighted article bodies are
  reproduced, in line with fair, non-infringing use of publicly available
  metadata.

## `processed/` (DERIVED + MODEL OUTPUT)

Generated by `python scripts/build_dataset.py`, which calls the reusable
`signalflow` package (`src/signalflow/`) — the same code the backend API and
the test suite import. Nothing here is computed by hand.

- **`event_study.json`** — returns, market-model abnormal returns, cumulative
  abnormal returns, volatility and volume statistics for the event window.
- **`sentiment.json`** — VADER sentiment scores and daily information
  intensity computed directly from the real headlines in
  `news_headlines.csv`.
- **`diffusion.json`** — fitted exponential/logistic diffusion model
  parameters, goodness-of-fit metrics, and the information absorption time
  estimates.
- **`hypotheses.json`** — the four pre-registered hypotheses (see
  `docs/research_report.md`) with their test statistics and conclusions.

All of `processed/` is derived deterministically from `raw/`. Delete it and
re-run `scripts/build_dataset.py` at any time to regenerate it byte-for-byte
(modulo floating point).
